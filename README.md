# 车况小组件（Web 演示版）

基于一汽丰田用车场景的第三方 Web App 演示：桌面添加到主屏幕后作为小组件使用，提供**剩余续航、车辆状态、定位呈现、钥匙入口**四个板块。

> 版本 v0.1.0 ｜ Node.js >= 18 ｜ 无外部依赖，`npm start` 即可运行

## 一、能力边界（先读）

本项目在**没有官方开放平台授权**的条件下开发，以下结论是工程前提，不是待补的小问题：

| 能力 | 真实数据来源 | 当前实现 | 阻塞点 |
|---|---|---|---|
| 剩余续航 / 油量电量 | 车联网 TSP 车辆状态接口 | 演示数据 + 手动录入，字段模型已就位 | 无开放平台授权；官方接口带签名与风控 |
| 车辆定位（经纬度、地址、时间） | TSP 定位接口 + 逆地理编码 | 浏览器 GPS（手机位置），非车端位置 | 定位属敏感个人信息，需单独授权与接口权限 |
| 车门 / 车窗 / 胎压 / 总里程 | TSP 车辆状态接口 | 界面与字段就位，数据本地录入 | 同续航项 |
| 蓝牙钥匙（解 / 锁 / 启动） | 车端 PEPS + 云端签发凭证 + 安全元件 | **仅深链唤起官方 App**，不做协议模拟 | 凭证由厂商签发并绑定设备安全元件，第三方无签发能力 |
| 远程控车（空调 / 闪灯 / 鸣笛） | 官方车联网体系 | 不提供 | 同蓝牙钥匙，第三方只能做入口 |
| 桌面小组件展示 | PWA「添加到主屏幕」 | 支持，离线缓存静态壳 | 真正的原生桌面 Widget（Android AppWidget / iOS WidgetKit）需对应原生工程 |

**合规说明**：本项目不抓取、不破解官方 App 的私有接口，不绕过签名风控，不存储真实车主凭证。真实车况接入需要通过一汽丰田官方开放平台申请资质与授权后，在预留的 `OfficialProvider` 适配层内补齐。

## 二、本地运行

```bash
npm start
# 默认 http://localhost:3000 ，可用 PORT=3001 npm start 改端口
```

浏览器打开后：

1. 登录页为**演示占位账号**：任意非空账号密码即可进入，不连接一汽丰田服务器；
2. 车况、定位、钥匙、设置四个板块通过底部导航切换；
3. 在「设置」中填写车型、车牌、续航、百分比、能源类型等，数据保存在本机服务的 `data/state.json`；
4. 手机浏览器菜单选「添加到主屏幕 / 安装应用」，即可像小组件一样从桌面打开。

## 四、HTTP API

除 `POST /api/auth/login` 与 `GET /api/meta` 外，均需请求头 `Authorization: Bearer <token>`。占位令牌重启服务后失效。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 演示登录，入参 `username/password`，返回 `token` |
| GET | `/api/meta` | 数据源标识、能力矩阵、合规提示 |
| GET | `/api/vehicle/status` | 车型、车牌、续航、百分比、能源类型、锁止、车窗、胎压、总里程、采集时间 |
| PUT | `/api/vehicle/status` | 更新车辆资料 / 车况 / 数据源（字段有类型与范围校验） |
| GET | `/api/vehicle/location` | 经纬度、精度、采集时间 |
| PUT | `/api/vehicle/location` | 保存定位（纬度 -90~90，经度 -180~180） |
| GET | `/api/key/config` | 已配置的官方 App URL Scheme |
| PUT | `/api/key/config` | 保存 Scheme |
| POST | `/api/key/launch` | 返回可唤起的深链；未配置时返回提示 |

### 数据源分层

- `mock`（默认）：内置演示数值；
- `manual`：用户手动录入的数值；
- `official`：官方 TSP 占位，当前调用返回 `501 OFFICIAL_NOT_CONFIGURED`。

将来拿到授权后，只需在 `server/providers/official-provider.js` 内实现 TSP 客户端与字段映射，上层路由与前端无需改动。

## 五、已知限制与未验证项

- **未接真实车联网**：续航、定位、车况均为本机演示或手填，刷新不会从车端取数；
- **蓝牙钥匙 / 远程控车不可用**：仅提供官方 App 深链入口；
- **非原生小组件**：当前为 PWA，桌面图标与离线缓存可用，但不具备原生 Widget 的系统定时刷新能力；
- **鉴权为演示级别**：令牌存内存，无加密、无注册、无找回，不能作为生产账号体系；
- 本次交付在 Linux 云端完成：后端接口已用请求逐一验证；前端页面为昨天同款界面的 API 改造，语法与元素接线已静态核对，**浏览器内渲染与真机交互需在本地 `npm start` 后确认**（云端无浏览器与移动端编译环境）。

## 六、后续接入官方的前提条件

1. 通过一汽丰田官方开放平台申请开发者资质，获取 AppKey / Secret 与接口权限；
2. 走车主 OAuth 授权流程，取得带时效的访问凭证；
3. 在 `OfficialProvider` 中按官方 SDK / 接口规范实现状态、定位读取与逆地理编码；
4. 蓝牙钥匙与远程控车如官方开放第三方 SDK，按其文档接入；否则继续保留深链入口。
